## 👋 Hey there

This is the source code for my personal portfolio — built from scratch with React, dark/light mode, live GitHub API integration, and a space-themed animated background. No templates. Every pixel is intentional.

---

## ⚡ Tech Stack

| Layer | Tech |
|---|---|
| **Framework** | React 18 |
| **Styling** | SCSS Modules |
| **Icons** | Material UI Icons |
| **Routing** | React Router v6 |
| **Animations** | Pure CSS keyframes + IntersectionObserver |
| **Data** | GitHub REST API |
| **Deployment** | Vercel |

---

## 🚀 Features

- 🌗 **Dark / Light mode** — Space theme with flying rockets & a ringed planet in dark mode. Aurora blob background in light mode.
- 🧠 **Live GitHub Projects** — Fetches repos directly from the GitHub API with README modal viewer.
- 🎯 **Scroll reveal animations** — IntersectionObserver-powered fade-in on every section.
- 📱 **Fully responsive** — Mobile-first layout with a full-screen navigation overlay.
- 🏆 **Certifications** — Linked badges with direct verification URLs.
- ⭐ **Featured Project** — Melolem e-commerce platform highlighted with a custom card.

